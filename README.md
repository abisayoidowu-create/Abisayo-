# Abisayo-
How to write an affidavit 
To write an affidavit, Begin with the title
Include the name of the court, judicial division, and relevant case details, State the names of the parties to the case. 
State the full name, occupation, nationality, address, and other relevant details of the person making the affidavit. 
Attach and identify documents referred to in the affidavit. 
End with the jurat and signature section.
